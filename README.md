✨ ¿Qué es esto?
ENCIP es una Single Page Application (SPA) futurista, emocional y altamente interactiva desarrollada para el Instituto Universitario ENCIP — una institución educativa con más de 20 años de trayectoria y validez oficial SEP a nivel federal.
Esta experiencia web fue diseñada para transmitir que ENCIP no solo ofrece educación, forma personas capaces de dirigir su vida, tomar decisiones y navegar su futuro con propósito.
